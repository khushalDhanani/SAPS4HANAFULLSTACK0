## 2. Configuration Options for the Functional Consultant

### Option 1: Map `W01` / `Z007` -> `E10` ("Pieces")
- **Customizing Key**: `LGNUM = 'W01'`, `VHART = 'Z007'`, `LETYP = 'E10'`
- **Technical Evidence**:
  - Aligns with existing `LQUA` inventory and confirmed Transfer Orders in `W01` which already carry `LETYP = 'E10'`.
  - Matches the physical description of packaging type `Z007` ("Boxes") mapping to discrete pieces (`E10`).
- **Potential Considerations**:
  - Warehouse `W15` historically mapped `Z007` to `E1`. Choosing `E10` in `W01` establishes warehouse-specific SUT assignment rather than uniform enterprise-wide assignment.

### Option 2: Map `W01` / `Z007` -> `E1` ("Drum 25 Ltr")
- **Customizing Key**: `LGNUM = 'W01'`, `VHART = 'Z007'`, `LETYP = 'E1'`
- **Technical Evidence**:
  - Aligns with the customizing precedent in Warehouse `W15` (`DS4K905282`), where `Z007` maps to `E1`.
  - Aligns with existing `W01` entries in `T319A`, where types `0001` and `Z003` both map to `E1`.
- **Potential Considerations**:
  - In `W01`, `T307T` explicitly describes `E1` as `"Drum 25 Ltr"`, which is semantically mismatched for cardboard boxes.
  - Quants created during delivery picking would inherit `LETYP = 'E1'`, introducing a mixed storage unit type against existing `E10` quants.

Before releasing and importing the customizing transport, the functional consultant should consider:

1. **Storage Unit Type Search (`T334P`) & Putaway Strategy**:

   - Is it corporate policy that packaging material type `Z007` ("Boxes") map to the identical Storage Unit Type across all company warehouses, or is SUT assignment warehouse-specific based on physical storage structures?
